# Code of Conduct

Be kind, be patient, assume good intent. Everyone is welcome here, whatever their background, identity or
experience.

Not OK: harassment, insults, personal or political attacks, unwelcome sexual attention, publishing others' private
information, and any conduct that would be inappropriate in a professional setting.

Maintainers may remove comments, code or contributors that break these rules. To report a problem, contact the
maintainers privately via the email on the maintainer's GitHub profile or through [psem.me](https://psem.me/).
Reports are kept confidential.

This applies in the repository, issues, discussions and any project space. Adapted in spirit from the
[Contributor Covenant](https://www.contributor-covenant.org/).
